# Indian Retail Sales & Profitability Executive Dashboard (2024–2025)

**Data Analytics Virtual Internship — Elevate Labs**

🔗 **Live Interactive Dashboard:** https://public.tableau.com/app/profile/chelsea.nayak/viz/IndianRetailSalesProfitabilityAnalysis2024-2025/Dashboard1
## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data cleaning, handling missing values, removing duplicates, date formatting, and Pivot Tables.
* **SQL:** Data querying, filtering, and aggregation (`GROUP BY`, `SUM`, `AVG`).
* **Tableau:** Data modeling, KPI calculations, and building an interactive executive dashboard.

## 📊 Capstone Project Highlights
* **Dataset:** 15,000 Indian retail orders (2024–2025) tracking Order Date, Product Category, Sales Channel, Quantity, Discount, Net Sales, and Net Profit.
* **Key Metrics Tracked:**
  * **Total Net Sales:** ₹72.27M
  * **Total Net Profit:** ₹27.28M
  * **Overall Profit Margin:** 37.7%
* **Key Findings:**
  * Identified margin trade-offs between high-revenue categories (Technology) and high-margin categories (Beauty).
  * Highlighted the direct online consumer channel as a major driver of net profit.
  * Tracked steady month-over-month sales stability across 2024–2025.
